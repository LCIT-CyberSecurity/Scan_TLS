# Claude Code instructions

Follow the repository's shared contributor contract in [`AGENTS.md`](AGENTS.md). Before changing code, read the Jira ticket and all comments, check the latest `_SANDBOX` state and open PRs, and work on a dedicated ticket branch. Keep changes scoped, preserve security and existing behavior, run relevant requested checks, and record real results in Jira. Never merge or deploy without explicit owner authorization covering that action.
